# 얼음땡 (가제) — 기획안

**처음 만난 다섯 명이 18분짜리 아이스브레이킹을 함께 하면,
각자의 캐릭터 카드와 팀 리포트가 나오는 웹 서비스.**

---

## 1. 서비스 정의

팀 프로젝트를 막 시작한 사람들이 서로를 빠르게 파악하는 데 쓰는 도구입니다.
게임을 하는 동안 각자의 선택과 서로에 대한 추측이 쌓이고, 끝나면 그 기록이
**개인 캐릭터 카드**와 **팀 리포트**로 정리됩니다.

리포트는 진지한 성격 검사가 아닙니다. **익살스럽게 비꼬다가 마지막에 칭찬 한 줌**을
던지는 톤으로, 팀원끼리 서로 보여주며 웃는 것이 목적입니다.

## 2. 전제

| 항목 | 값 |
|---|---|
| 인원 | 5명 |
| 진행 시간 | **18분** (리포트 열람 시간은 별도) |
| 기기 | **각자 폰 1대씩** + 공용 화면 1개 |
| 장소 | 대면 · 비대면 모두 가능 |
| 카테고리 | 팀 프로젝트 |

**공용 화면**은 호스트 폰이거나 노트북 화면 공유입니다. 진행과 공개만 담당하며
**호스트가 눌러야 넘어가는 단계는 없습니다.** 전원이 제출하면 자동으로 공개되므로
호스트도 다른 참가자와 똑같이 게임에 참여합니다.

## 3. 설계 원칙

1. **혼자 폰을 들여다보는 시간을 최소로.** 한 번에 3~5초짜리 선택만 요구합니다.
2. **모든 입력은 동시에, 공개도 동시에.** 전원이 제출하면 공용 화면이 한꺼번에
   펼칩니다. 이 공개 순간이 대화를 만듭니다.
3. **자기 이야기를 내고, 남의 이야기를 추측한다.** 이 두 가지가 데이터원이자
   재미의 축입니다.
4. **결과는 언제나 좋게 나온다.** 등급의 최하가 `S`, 궁합의 최하가 `B`입니다.
   나쁜 결론이 구조적으로 나오지 않습니다.
5. **한 화면으로 여러 단계를 돌린다.** 문제 → 제출 → 동시 공개라는 껍데기 하나가
   5단계 중 4단계를 담당합니다.

## 4. 진행 구성 — 18분

| # | 단계 | 시간 | 각자 폰 | 공용 화면 |
|---|---|---|---|---|
| 1 | **입장** | 2:00 | 닉네임 · 성별 · MBTI 입력 | 들어온 사람이 순서대로 표시 |
| 2 | **첫인상 투표 ①** | 2:00 | 5문항, 각 한 명 지목 | 득표 동시 공개 |
| 3 | **동시에 답하기** | 5:00 | 이지선다 8문항 | 문항마다 누가 뭘 골랐는지 공개 |
| 4 | **둘은 진실, 하나는 거짓** | 5:00 | 자기 얘기 3줄 입력 → 남의 거짓 찾기 | 한 명씩 띄우고 정답 공개 |
| 5 | **첫인상 투표 ②** | 2:00 | ②와 같은 5문항 | 득표 공개 + **처음과 비교** |
| 6 | **누가 나를 맞힐까** | 2:00 | 내 유형 찍기 → 남들 유형 배정 | 정답 공개 |

### 4-1. 입장

닉네임, 성별, MBTI를 받습니다. 성별은 **남 / 여** 두 가지입니다.
MBTI는 리포트 서술을 두껍게 하는 데만 쓰이며, **능력치와 유형 판정에는
사용하지 않습니다.**

### 4-2. 첫인상 투표 ① — 5문항

아직 서로에 대해 아무것도 모르는 상태에서 다섯 문항에 한 명씩 지목합니다.
자기 자신은 고를 수 없습니다.

| # | 질문 | 대응 능력치 |
|---|---|---|
| 1 | 첫 회의에서 제일 먼저 말할 것 같은 사람은? | 주도력 |
| 2 | 결정을 제일 빨리 내릴 것 같은 사람은? | 순발력 |
| 3 | 발표를 제일 잘할 것 같은 사람은? | 표현력 |
| 4 | 힘들 때 제일 먼저 물어봐줄 것 같은 사람은? | 공감력 |
| 5 | 남의 거짓말을 제일 먼저 눈치챌 것 같은 사람은? | 관찰력 |

득표수는 그대로 **점선 레이더**가 됩니다. 5명이므로 한 문항당 최대 4표이고,
`득표수 ÷ 4 × 5` 로 0~5 값이 됩니다.

### 4-3. 동시에 답하기 — 이지선다 8문항

각자 폰에 A/B 두 개가 뜹니다. 전원이 고르면 공용 화면이 **누가 어느 쪽을
골랐는지** 한꺼번에 펼칩니다. 편이 갈리는 순간이 대화를 만듭니다.

| # | 상황 | A | B | 능력치 |
|---|---|---|---|---|
| 1 | 첫 회의, 아무도 말이 없다 | 내가 먼저 시작한다 | 누가 말할 때까지 기다린다 | 주도력 |
| 2 | 역할을 정한다 | 하고 싶은 걸 먼저 말한다 | 남는 걸 맡는다 | 주도력 |
| 3 | 방향이 틀린 것 같다 | 지금 말한다 | 일단 해보고 말한다 | 주도력 |
| 4 | 단톡방에 할 말이 생겼다 | 생각나면 바로 쓴다 | 정리해서 한 번에 쓴다 | 표현력 |
| 5 | 발표자를 정한다 | 내가 한다 | 남이 하면 좋겠다 | 표현력 |
| 6 | 아이디어가 떠올랐다 | 다듬기 전에 던진다 | 확신이 들 때만 꺼낸다 | 표현력 |
| 7 | 팀원이 마감을 놓쳤다 | 무슨 일 있냐고 먼저 묻는다 | 언제까지 되냐고 먼저 묻는다 | 공감력 |
| 8 | 의견이 갈렸다 | 소수 의견을 한 번 더 듣는다 | 다수로 빨리 정한다 | 공감력 |

A가 해당 능력치의 높은 쪽입니다. **응답에 걸린 시간도 함께 기록**되며
순발력의 재료가 됩니다.

### 4-4. 둘은 진실, 하나는 거짓

각자 자기 얘기 **세 줄**을 입력합니다. 그중 하나는 거짓입니다.
공용 화면에 한 명씩 뜨면 나머지 네 명이 각자 폰에서 거짓 하나를 고르고,
전원이 고르면 정답이 공개됩니다.

- 여기서 입력된 문장은 **리포트에 그대로 인용**됩니다.
- 남의 거짓을 맞힌 횟수가 **관찰력**의 절반을 만듭니다.
- 아무도 못 맞힌 문장은 팀 리포트 하이라이트로 올라갑니다.

### 4-5. 첫인상 투표 ② — 같은 5문항

4-2와 **완전히 같은 다섯 문항**을 다시 묻습니다.
전후 득표 차이가 곧 "게임이 실제로 먹혔는가"의 증거이며,
개인 카드의 **인상 변화** 항목과 `첫인상 배신자` 칭호의 근거가 됩니다.

### 4-6. 누가 나를 맞힐까

1. 각자 **자기 유형을 먼저 하나 찍습니다.** (자기 인식 격차용)
2. 유형 카드가 이름 없이 뜹니다. 각자 폰에서 누구 것인지 배정합니다.
3. 전원 제출되면 정답이 공개되고 관찰력 점수가 합산됩니다.

## 5. 능력치 5개

사용자에게는 **능력치**로 표기하고, 오각형 레이더로 보여줍니다.

| 표기 | 코드 | 무엇을 재나 | 출처 |
|---|---|---|---|
| **주도력** | `DOM` | 판을 먼저 벌리나 | 이지선다 1·2·3 |
| **순발력** | `SPD` | 얼마나 빨리 결정하나 | 이지선다 8문항 평균 응답 시간 |
| **표현력** | `EXP` | 자기를 얼마나 드러내나 | 이지선다 4·5·6 |
| **공감력** | `EMP` | 남을 얼마나 살피나 | 이지선다 7·8 |
| **관찰력** | `OBS` | 남을 얼마나 맞히나 | 거짓 찾기 + 유형 맞히기 정답률 |

모두 **0.0 ~ 5.0**입니다.

### 산출식

```
주도력 = (문항 1·2·3 중 A 개수 / 3) × 5
표현력 = (문항 4·5·6 중 A 개수 / 3) × 5
공감력 = (문항 7·8   중 A 개수 / 2) × 5

순발력 = 평균 응답 시간을 절대 기준으로 환산
         3초 이하 → 5.0
         12초 이상 → 0.0
         사이는 선형

관찰력 = (거짓 찾기 정답 수 + 유형 맞히기 정답 수) / (4 + 4) × 5
```

순발력을 팀 내 순위가 아니라 **절대 기준**으로 잡는 이유는, 팀이 바뀌어도
같은 사람의 값이 흔들리지 않게 하기 위해서입니다.

### 두 종류의 선

개인 카드의 오각형에는 선이 셋 겹칩니다.

| 선 | 뜻 | 출처 |
|---|---|---|
| 실선 | 오늘의 나 | 능력치 5개 |
| 점선 (연함) | 처음에 본 나 | 첫인상 투표 ① |
| 점선 (진함) | 끝나고 본 나 | 첫인상 투표 ② |

두 점선이 실선 쪽으로 붙어가는 그림이 곧 "서로를 알아갔다"는 뜻입니다.

## 6. 유형 8종

`주도력 × 표현력 × 관찰력` 세 가지를 **2.5 기준**으로 갈라 여덟 가지입니다.
동점(±0.3)이면 **순발력**이 높은 쪽으로 기웁니다.

| 코드 | 주도 | 표현 | 관찰 | 이름 | 부제 |
|---|:-:|:-:|:-:|---|---|
| `T1` | H | H | H | **판 짜는 사람** | 다 보고 다 말하고 다 정한다 |
| `T2` | H | H | L | **확성기** | 말은 제일 많은데 남 얘긴 안 들림 |
| `T3` | H | L | H | **뒷자리 판사** | 본인은 안 나서는데 판결은 다 내림 |
| `T4` | H | L | L | **직진** | 말은 아끼고 결정은 안 아낌 |
| `T5` | L | H | H | **해설위원** | 다 알면서 정작 자기 패는 안 냄 |
| `T6` | L | H | L | **분위기 담당** | 무슨 말인지는 몰라도 재밌음 |
| `T7` | L | L | H | **CCTV** | 말은 없는데 다 보고 있었음 |
| `T8` | L | L | L | **정직한 무임승차** | 오늘은 그냥 앉아 있었음 |

유형 이름과 부제는 세게 갑니다. 순화는 코멘트 마지막 줄의 칭찬이 받습니다.

**카드 이미지**는 8종 각각 하나씩 필요합니다. 초기 구현에서는 유형별
**색 + 심볼**로 구분하고, 일러스트는 같은 레이아웃 위에 교체합니다.

## 7. 칭호

유형은 **절대 평가**(본인 기록만), 칭호는 **상대 평가**(팀 안에서의 순위·조건)입니다.
팀이 바뀌면 칭호도 바뀝니다.

| 칭호 | 조건 |
|---|---|
| **관찰왕** | 거짓 찾기 + 유형 맞히기 정답 합계 1위 |
| **완벽한 거짓말쟁이** | 아무도 못 맞힌 거짓말을 냄 |
| **첫인상 배신자** | 전후 득표 변화량 최대 |
| **예측대로** | 전후 득표 변화량 최소 |
| **최다 지목** | 첫인상 투표 총 득표 1위 |
| **번개손** | 평균 응답 시간 1위 |
| **제일 오래 고민한 사람** | 평균 응답 시간 최하위 |
| **소수파** | 이지선다에서 혼자 다른 쪽을 고른 횟수 1위 |
| **만장일치** | 남들과 선택이 제일 많이 겹친 사람 |
| **자기 예언자** | 자기 유형을 스스로 맞힘 |

**모든 참가자는 최소 하나를 받습니다.** 아무 조건에도 안 걸리면 `예측대로`가
기본값입니다.

## 8. 궁합 — S / A / B

두 사람의 능력치 다섯 개 차이를 합산해 등급을 매기고, **보완**과 **닮음** 중
하나를 태그로 붙입니다.

```
거리 = Σ |A의 능력치 − B의 능력치|   (0 ~ 25)

궁합 등급
  S : 거리가 아주 크거나 아주 작다   (서로를 확실히 채우거나 확실히 닮았다)
  A : 그 사이
  B : 어중간하다

태그
  거리 ≥ 12.5 → 보완
  거리 <  12.5 → 닮음
```

**최하가 B입니다.** 나쁜 궁합은 나오지 않습니다.
거리가 크면 "서로 없는 걸 채운다", 작으면 "말이 안 통할 일이 없다"로 서술합니다.

팀 등급(`SSS`~`S`)과는 눈금이 다르므로, 화면에서 팀 쪽은 **등급**,
두 사람 사이는 **궁합**으로 라벨을 구분합니다.

## 9. 팀 등급 — SSS / SS+ / SS / S+ / S

네 가지 지표를 보고 매깁니다. **모두 "높을수록 좋다"이며 최하 등급이 `S`입니다.**

| 지표 | 재는 것 |
|---|---|
| **분산도** | 능력치 1위가 서로 다른 사람에게 얼마나 흩어졌나 |
| **상호 이해도** | 거짓 찾기 전체 정답률 |
| **인상 변화량** | 첫인상 투표 전후로 최다 득표자가 바뀐 문항 수 |
| **의견 다양성** | 이지선다에서 편이 갈린 문항 수 |

| 등급 | 조건 |
|---|---|
| **SSS** | 네 지표 모두 상위 |
| **SS+** | 셋 상위 |
| **SS** | 둘 상위 |
| **S+** | 하나 상위 |
| **S** | 그 외 |

등급이 낮아도 문장은 좋게 나갑니다. 능력치가 몰렸으면 "성향이 비슷해 말이 잘
통한다", 의견이 안 갈렸으면 "이미 합이 맞는다"로 받습니다.
**등급은 크게, 근거는 네 줄로** 보여줍니다.

## 10. 결과 화면 — 세 메뉴

게임이 끝나면 허브 화면에서 세 갈래로 나뉩니다.

### 10-1. 개인 리포트

| 칸 | 내용 |
|---|---|
| 헤더 | 유형 이름 + 부제 + 닉네임 + MBTI |
| 오각형 레이더 | 실선 1개 + 점선 2개 |
| 코멘트 3줄 | ①돌려까기 ②오늘의 장면 ③뒤집어 칭찬 |
| 인상 변화 | 처음 득표 → 나중 득표 |
| 팀원별 궁합 | 4명 각각 등급 + 태그 + 한 줄 |
| 칭호 | 1~2개 |
| 자기 인식 격차 | 내가 찍은 나 / 실제 |

**예시**

```
뒷자리 판사
본인은 안 나서는데 판결은 다 내림
종훈 · INTJ

           주도력
             ●
   관찰력 ╱     ╲ 순발력
        ●         ●
         ╲       ╱
   공감력 ●─────● 표현력

주도력 2.1 · 순발력 3.8 · 표현력 1.9 · 공감력 3.2 · 관찰력 4.1

남 의심하는 데는 여덟 문항 내내 망설임이 없었는데,
정작 본인 순서에서는 제일 안전한 거짓말을 골랐습니다.

"고등학교 때 전국대회 나간 적 있음" — 네 명 중 셋이 속았습니다.
재미없는 거짓말이 제일 잘 통한다는 걸 아는 사람입니다.

그 계산이 남의 거짓말을 셋이나 잡아냈습니다.
이 팀에서 제일 먼저 눈치채는 사람입니다.

── 첫인상이 이렇게 바뀌었습니다
   처음 — 잠수 탈 것 같은 사람        3표
   나중 — 제일 먼저 눈치챌 것 같은 사람  4표
   15분 만에 도망갈 사람에서 감시자가 됐습니다.

── 팀원별 궁합
   지민   S   보완   능력치가 정반대라 서로 없는 걸 채웁니다
   서연   S   보완   서연이 말을 꺼내면 종훈이 정리합니다
   현우   A   닮음   여덟 문항 중 여섯을 똑같이 골랐습니다
   태윤   B   닮음   둘 다 남 말을 잘 안 믿습니다

🏅 관찰왕   🏅 첫인상 배신자

내가 찍은 나 — 판 짜는 사람 / 실제 — 뒷자리 판사
```

### 10-2. 팀 리포트

**예시**

```
                    SS+
        말은 적은데 결론은 빨리 나는 팀

── 이 등급이 나온 이유
   능력치가 골고루 흩어졌습니다
     다섯 명이 각각 다른 능력치에서 1등입니다. 한 사람이 다 하는 팀이 아닙니다
   서로를 잘 읽습니다
     거짓말 스무 개 중 열셋을 잡아냈습니다
   인상이 많이 바뀌었습니다
     다섯 문항 중 셋에서 최다 득표자가 바뀌었습니다.
     18분 안에 서로에 대한 판단이 실제로 갱신됐다는 뜻입니다
   의견은 갈렸습니다
     여덟 문항 중 다섯에서 편이 갈렸습니다. 회의가 조용히 끝날 팀은 아닙니다

── 추천 역할 (각 능력치 1위가 한 자리씩)
   총괄       지민   주도력 1위. 판을 먼저 벌립니다
   발표       태윤   표현력 1위. 말이 제일 잘 붙습니다
   기록·문서   종훈   관찰력 1위. 남이 흘린 걸 다 봅니다
   조율       서연   공감력 1위. 갈렸을 때 중간을 찾습니다
   실행       현우   순발력 1위. 제일 먼저 손이 나갑니다

── 오늘의 장면 셋
   🥇 인상이 제일 많이 바뀐 사람 — 종훈
      잠수 탈 것 같다는 표를 세 장 받고 시작해서,
      제일 먼저 눈치챌 것 같은 사람으로 끝났습니다.
   🎭 아무도 못 잡은 거짓말 — 현우
      "라면에 계란 안 넣음." 다섯 명 전원이 진실이라고 믿었습니다.
   💥 제일 크게 갈린 문항
      마감 3일 전 vs 하루 전 — 3 대 2.
      이 팀의 첫 번째 싸움은 여기서 납니다.
```

**추천 역할**은 능력치 1위끼리 한 자리씩 맡습니다. 한 사람이 두 능력치에서
1위이면 두 번째 자리는 그 능력치 2위에게 넘어갑니다.

### 10-3. 게임으로 가기

만들어진 페르소나를 넘겨받아 이어서 진행하는 게임의 입구입니다.
아이스브레이킹 쪽에서는 **페르소나 데이터를 넘기는 것까지**를 담당합니다.

## 11. 문구 규칙

1. **숫자를 문장에 쓰지 않는다.** "6초 만에 골랐다" ✕ → "손이 먼저 나갑니다" ○
   숫자는 레이더가 이미 보여줍니다.
2. **까는 대상은 오늘 한 행동이지 사람이 아니다.** "게으르다" ✕ →
   "본인 차례에만 성실했다" ○
3. **마지막 줄은 앞에서 깐 바로 그 행동을 뒤집어 칭찬한다.** 다른 장점을 새로
   꺼내지 않습니다. 이게 있어야 돌려까기가 되고, 없으면 그냥 욕이 됩니다.
4. **외모 · 성별 · 나이 · 직업은 소재로 쓰지 않는다.**
5. **첫인상 득표는 놀리되 사실로 확정하지 않는다.** 남의 시선일 뿐입니다.
6. **팀 리포트에는 비꼼을 넣지 않는다.** 개인은 놀려도 되지만 팀 전체를 까면
   자리 분위기가 죽습니다.

### 사전 구조

```
comment_dict[ability][direction][gap] = [문장 3~5개]
closing_dict[opening_id]              = [뒤집는 문장 2~3개]
```

마지막 줄은 **반드시 첫 줄과 짝지어진 사전**에서 뽑습니다.
랜덤으로 섞이면 문장이 따로 놉니다.

### 첫 줄 사전 — 첫인상과 실제가 어긋난 자리

| 어긋난 지점 | 코멘트 |
|---|---|
| 말 많을 줄 알았는데 조용 | 말 많을 줄 알았는데 오늘은 고개만 끄덕였습니다. 뭘 아끼는지는 모르겠지만 아끼긴 하더군요. |
| 조용할 줄 알았는데 말 많음 | 입이 쉬질 않습니다. 옆 사람이 숨 쉴 틈을 찾다가 포기했습니다. |
| 안 나설 줄 알았는데 주도 | 남 의심하는 데는 망설임이 없습니다. 본인 얘기 할 때만 갑자기 신중해지고요. |
| 정 없을 줄 알았는데 공감 | 정 없는 척은 다 하는데 남은 제일 많이 챙겼습니다. 들키셨습니다. |
| 따뜻할 줄 알았는데 냉정 | 따뜻할 거라더니 오늘은 아무도 안 챙겼습니다. 본인 순서 오는 것만 기다렸죠. |
| 느긋할 줄 알았는데 제일 빠름 | 고민이 없습니다. 여덟 문항을 남들 세 문항 푸는 동안 끝냈습니다. |
| 빠를 줄 알았는데 제일 느림 | 한 번 고르는 데 세 번 뜸을 들입니다. 그동안 판이 두 번 바뀌었습니다. |
| 어긋난 데 없음 | (행동 관찰로 대체) 끝까지 조용했는데, 이상하게 이 사람 차례에는 다들 답을 늦게 냈습니다. |

### 마지막 줄 사전 — 뒤집어 칭찬

| 앞에서 깐 것 | 뒤집는 줄 |
|---|---|
| 입이 쉬질 않음 | 시끄러웠지만 덕분에 아무도 어색할 틈이 없었습니다. |
| 말이 없음 | 말수는 제일 적은데 결론은 이 사람이 냈습니다. |
| 남 의심에 거침없음 | 그 의심이 두 번 다 맞았습니다. 판을 정리한 건 이 사람입니다. |
| 아무도 안 챙김 | 대신 아무도 못 본 걸 혼자 보고 있었습니다. |
| 고민이 없음 | 그 속도 덕분에 회의가 제시간에 끝났습니다. |
| 너무 오래 걸림 | 늦게 낸 답이 제일 정확했습니다. |

## 12. MBTI 활용

MBTI는 **능력치 산출과 유형 판정에 관여하지 않습니다.**
리포트 문장을 쓸 때 **컨텍스트**로만 들어가 서술을 두껍게 합니다.

```
컨텍스트 : MBTI=INTJ
           능력치=[2.1, 3.8, 1.9, 3.2, 4.1]
           거짓말="고등학교 때 전국대회 나간 적 있음" (3명 속임)
           첫인상 전=잠수 3표 / 후=눈치 4표
금지어   : MBTI, INTJ, I, N, T, J, 내향, 외향, 성격유형, 성향검사
```

MBTI가 컨텍스트에 있으면 "혼자 있는 걸 편해하면서 판은 다 읽는" 같은 문장이
나오고, 없으면 숫자만 가지고 써야 해서 밋밋해집니다.
**판정은 건드리지 않고 문장만 두껍게 하는 자리**입니다.

리포트 본문에 MBTI가 언급되는 곳은 **개인 카드 헤더의 닉네임 옆 한 곳뿐**입니다.

## 13. 데이터 모델

```
Session(id, code, status, created_at)

Player(id, session_id, nickname, gender, mbti, seat_no, is_host)

Answer(id, session_id, player_id, question_no, choice, elapsed_ms)
       -- 이지선다 8문항. elapsed_ms가 순발력의 재료

Statement(id, session_id, player_id, slot, text, is_lie)
          -- 둘은 진실 하나는 거짓. slot ∈ {1,2,3}

Guess(id, session_id, kind, guesser_id, target_player_id,
      target_statement_id, target_type_code, round_no)
      -- kind ∈ {IMPRESSION_PRE, IMPRESSION_POST, LIE, TYPE}
      -- 첫인상 투표 · 거짓 찾기 · 유형 맞히기를 이 하나로 커버

Ability(session_id, player_id, code, value, source)
        -- code ∈ {DOM, SPD, EXP, EMP, OBS}
        -- source ∈ {BEHAVIOR, IMPRESSION_PRE, IMPRESSION_POST}

Report(session_id, player_id, type_code, comment_lines, badges, quote)
```

**지켜야 할 것**

- `Guess` 하나로 네 종류의 추측을 커버합니다. 테이블을 늘리지 않습니다.
- `IMPRESSION_PRE` / `IMPRESSION_POST` 소스는 **점선 레이더와 인상 변화
  전용**입니다. 능력치 본값이나 유형 판정에 섞지 않습니다.
- `Player`(방 참가 기록)와 사용자 식별자를 혼동하지 않습니다.
- MBTI는 `Player`에만 있고 `Ability` 산출식에는 등장하지 않습니다.
