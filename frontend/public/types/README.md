## 지금 들어 있는 것

원본 정사각 일러스트(1254px)를 **512×512 WebP, 품질 85**로 줄인 것입니다.
장당 30~70KB, 여덟 장 합쳐 0.4MB 안쪽입니다.

## 갈아끼울 때

- **정사각.** 화면에서 132px(공개)과 88px(카드)로 그려지므로 512px면 고해상도
  화면에서도 충분합니다. 그보다 크게 넣을 이유가 없습니다
- **표의 색을 그대로** 씁니다. 유형 이름 글자가 이 색으로 찍히므로, 그림이
  다른 색이면 카드 안에서 둘이 따로 놉니다
- **어두운 바탕(`#0E1230`)에 얹힙니다.** 그림에 자체 테두리가 있어 배경이
  불투명해도 되지만, 가장자리가 밝으면 바탕에서 뜹니다
- 장당 **200KB 이하**를 유지합니다. 유형 맞히기 화면은 방 인원수만큼(최대
  여덟 장) 한 번에 띄웁니다

변환은 Pillow로 한 줄이면 됩니다 (`pip install Pillow`). 앱이 쓰는 라이브러리가
아니라 이미지 만들 때만 쓰는 도구라 `requirements.txt` 에는 넣지 않았습니다.

```python
from PIL import Image
Image.open(src).convert("RGB").resize((512, 512), Image.LANCZOS) \
     .save("T1.webp", "WEBP", quality=85, method=6)
```

## 파일명을 바꾸고 싶다면

고쳐야 합니다. 두 곳이 어긋나면 화면과 API가 다른 파일을 가리킵니다.
