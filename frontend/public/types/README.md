# 유형 카드 이미지

여기에 `T1.png` ~ `T8.png` 를 넣으면 리포트와 유형 맞히기 화면이 이모지 대신
그 이미지를 씁니다. **파일이 없으면 이모지로 그려지므로**, 여덟 장을 한 번에
안 만들어도 되고 하나씩 채워도 됩니다.

| 파일 | 유형 | 이모지 | 색 |
|---|---|:-:|---|
| `T1.png` | 셀프 사회자 | 🎤 | `#FF2E88` |
| `T2.png` | 직구 마스터 | ⚾ | `#FF6B35` |
| `T3.png` | 뒷자리 미어캣 | 👀 | `#FFC531` |
| `T4.png` | 무면허 라이더 | 🏍️ | `#FF4757` |
| `T5.png` | 방구석 박사 | 🎓 | `#7B61FF` |
| `T6.png` | MZ 응원단장 | 📣 | `#C6FF4E` |
| `T7.png` | 은둔형 명탐정 | 🔍 | `#2E86FF` |
| `T8.png` | 평화성애자 | 🕊️ | `#7FD8C9` |

## 만들 때

- **정사각형.** 화면에서 96px(리포트)과 44px(카드)로 줄여 쓰므로 **256×256 이상**을 권합니다
- **배경은 투명(PNG).** 앱 바탕이 짙은 남색(`#0E1230`)이라 흰 배경을 깔면 사각형이 그대로 드러납니다
- **어두운 바탕에서 보이는 색**으로. 위 표의 색이 그 유형의 색이니 그 계열로 잡으면 카드가 통일됩니다
- 파일당 **200KB 이하**를 권합니다. 여덟 장이 리포트 한 장에 다 뜨는 화면(유형 맞히기)이 있습니다

## 파일명을 바꾸고 싶다면

`frontend/src/data/types.js` 와 `backend/app/constants.py` 의 `image` 값을 같이
고쳐야 합니다. 두 곳이 어긋나면 화면과 API가 다른 파일을 가리킵니다.
